# Provenance and release boundary

The deterministic evidence summary adapts an MIT-licensed PLOS method for
keeping recorded synthetic checks separate from narrative claims and human
closure. The adaptation is Python, renames its public actions and documents,
checks common scope and clean-control source fingerprints,
and accepts direct structured receipt evidence rather than an application
framework's serialized tool result. PLOS copyright and MIT permission text
are retained in this repository.

The local fixture, authorization example, SQLite ledger, public contracts and
process documentation were written for this standalone reference. They do not
include customer examples, production bindings, private APIs or operational
scan results. All supplied data is synthetic.

The release does not port the original application's remote worker control,
identity/token services, model orchestration, deployment-bound observations or
private qualification archives. Those require their own dependencies,
permissions, reviewed target scope and operational verification. Implemented
receipt-verification concepts do not imply that every original workflow or
candidate capability is qualified or included here.

Python's standard library is required at runtime and is not redistributed in
this repository. There are no bundled third-party dependencies or model files.
